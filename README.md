# 🚗 Grand Theft Auto 2 (Game Boy Color)

Authentic *Grand Theft Auto 2* by Rockstar Games running online at 60 FPS in WebAssembly via EmulatorJS.

## 🕹️ Live Play
- **Play Online**: [https://marcuscaiado.github.io/gta-2/](https://marcuscaiado.github.io/gta-2/)
- **Arcade Hub 3D**: [https://marcuscaiado.github.io/nopex-arcade/](https://marcuscaiado.github.io/nopex-arcade/)
- **Arcade Catalog 2D**: [https://marcuscaiado.github.io/marcus-arcade/](https://marcuscaiado.github.io/marcus-arcade/)

## 🎮 Controls
- **D-Pad / Movement**: Arrow Keys or Mobile Touch D-Pad
- **Accelerate / Punch / Shoot**: Z (GBC B)
- **Reverse / Brake / Enter & Exit Vehicle**: A (GBC A)
- **Cycle Weapons**: Shift (Select)
- **Pause / Menu**: Enter (Start)
- **Gamepad**: Native USB & Bluetooth Gamepad supported
