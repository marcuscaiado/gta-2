# 🚗 Grand Theft Auto 2 (PlayStation 1)

Authentic 32-bit *Grand Theft Auto 2* by Rockstar Games running online at 60 FPS in WebAssembly via PCSX-ReARMed PSX core.

Features original radio stations, voice acting, pedestrian dialogue, 32-bit lighting and explosions, gang respect systems, and high-speed streaming with IndexedDB offline caching.

## 🕹️ Live Play
- **Play Online**: [https://marcuscaiado.github.io/gta-2/](https://marcuscaiado.github.io/gta-2/)

## 🎮 Controls (PS1 Layout)
- **D-Pad / Movement**: Arrow Keys or Mobile Touch D-Pad
- **Accelerate**: X (PS1 Cross)
- **Attack / Shoot**: Z (PS1 Square)
- **Enter / Exit Vehicle**: C (PS1 Circle)
- **Handbrake**: A (PS1 Triangle)
- **Cycle Weapons**: Q / E (PS1 L1 / R1)
- **Horn / Radio**: Shift (PS1 Select)
- **Pause / Mission Objectives**: Enter (PS1 Start)
- **Gamepad**: Native PlayStation, Xbox & Bluetooth Gamepad supported
